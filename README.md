# Metadata Reference Library (Java/Python)

Welcome to the metadata reference libary used for implementations of the Data and Trust Alliance (D&TA) Data Provenance Standards.

## Description

This project contains code references for the Python and Java implementations of data provenance standards entities.  External applications that import these reference implementations will be able to maintain data structure between different elements of the data provenance standards.

## Included files

### Java

Java implementations of the data provenance standards are found under the `/java` directory.  Each entity class is captured in its own Java implementation file.

### Python

Python implementations of the data provenance standards are found under the `/python` directory in file `/python/metadata_reference.py`.  All Python classes are contained within the same file.
